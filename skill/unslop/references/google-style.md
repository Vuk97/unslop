# Google developer docs digest

Local digest. Do not fetch the public guide. Open this file only when
ALWAYS_ON.md does not cover the question.

Attribution: https://developers.google.com/style (CC BY 4.0).

## Authority

Project style, then ALWAYS_ON, then this digest, then Merriam-Webster,
then Chicago, then the Microsoft Writing Style Guide when it is not
Microsoft-specific.

## Voice

Conversational, friendly, respectful. Not slang, not a joke, not a
press release. Sound like a knowledgeable friend. Avoid *please* in
instructions. Avoid *let's*. Avoid *simply* / *easy* / *quickly* in
procedures. Avoid exclamation marks in concept and reference prose.

## Person

Address the reader as *you*. Imperative for steps. Use *we* only for the
organization that authored the doc, and only when the antecedent is clear.
Use *user* for the end user of software the reader is building.

## Voice (grammar)

Active voice. Name the actor. Passive is fine when the object matters more
than the actor, or the actor is unknown or should be de-emphasized.

## Tense

Present tense for general behavior. *Will* only for a later event. Do not
pre-announce unreleased features.

## Sentence structure

Condition, goal, or circumstance first. Then the instruction. That lets the
reader skip a step that does not apply.

## Lists

Numbered for sequence. Bullets for an unordered set. Do not make a one-item
list. Introduce a list with a complete sentence. Parallel syntax. Capitalize
items. Periods on items that are sentences or contain verbs. No period on a
single word, a verb-less fragment, or an item that is only code or a title.

## Capitalization and commas

Sentence case for titles and headings. Serial comma. One space between
sentences.

## Formatting

Code identifiers, filenames, and flags in `code font`. UI labels in **bold**.
Descriptive link text. Dates: 2026-08-19 or August 19, 2026.

## Inclusive and global

No metaphors. No ableist language. No culturally specific jokes. Prefer
precise verbs over jargon. If you must use jargon, define it once.

## Dashes

The public Google guide uses em dashes. Unslop does not. Agent output that
uses em dashes reads as Claude-lish. Recast or use a hyphen-minus. This
house rule wins.
