# High-frequency words

Load this when ALWAYS_ON does not name the word. Source digest of
https://developers.google.com/style/word-list. Do not open that URL unless
the operator asked you to check a term that is not listed here.

| Avoid | Prefer |
| --- | --- |
| abort (general English) | stop, exit, cancel, end |
| actionable (filler) | useful, that you can act on |
| aka | also known as, or |
| allows you to | lets you |
| and/or | *and* or *or* |
| as (cause) | because |
| as of this writing | (delete) |
| above / below (document position) | earlier / later |
| click here | descriptive link text |
| click on | click |
| comprise | consist of, contain, include |
| currently (filler) | (delete) |
| desire, desired | want, need |
| e.g. | for example, such as |
| easy, easily, simply | (delete) |
| enable you to | lets you |
| etc. | such as, including |
| execute (start a program) | run |
| for instance | for example |
| functionality (filler) | features, capabilities, or a verb |
| in order to | to |
| leverage | use |
| please (instructions) | (delete) |
| utilize | use |
| via | through, with, from |
| we / let's (addressing the reader) | you, or the imperative |
| whitelist / blacklist | allowlist / denylist, or a precise verb |

Do not use *crazy*, *insane*, *dumb*, *hang* (for a stuck process; write
*stop responding*), *grandfathered* (write *legacy* or *exempt*), or *guys*
(write *everyone*).
